# 🚀 Quick Start Guide - Praktikum 13

## Instalasi & Menjalankan Aplikasi

### Step 1: Install Dependencies
```bash
flutter pub get
```

### Step 2: Run Application

**Pilihan A - Web (Chrome):**
```bash
flutter run -d chrome
```

**Pilihan B - Windows Desktop:**
```bash
flutter run -d windows
```

**Pilihan C - Auto Select Device:**
```bash
flutter run
```

## 🔧 Troubleshooting

### Problem: Error saat pub get
**Solution:**
```bash
flutter clean
flutter pub get
```

### Problem: Chrome tidak terbuka
**Solution:**
```bash
flutter devices
flutter run -d chrome
```

### Problem: Data tidak muncul
**Solution:**
- Check internet connection
- Tunggu loading selesai
